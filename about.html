关于 TSAI

一个把内容散落在三个平台的人，给自己做的一个汇总入口。

叫我 TSAI 就行。这里是个人主页，不写长博客，只做三件事： 把入口汇总清楚、把联系方式摆在明面上、让打开页面的人三秒内知道下一步点哪里。

我的内容大致分三类。折腾记录：装机、系统、工具链、各种踩坑和最后怎么解决的； 资源分享：值得留下来的东西，通常直接丢群里； 视频：把过程完整讲一遍，适合想跟着做的人。

三个平台的定位不重叠——群组用来即时交流，X 用来发短想法， 哔哩哔哩放长内容。同一个问题，在群里问通常最快有回应。

站点是纯静态的 HTML / CSS / JS，没有构建步骤、没有第三方库、没有统计脚本， 用 GitHub Pages 托管，源码结构一眼能看懂，想抄结构随时抄。

FAQ

几个常被问到的

群组为什么是邀请链接？

私密群组只通过邀请链接进入，好处是能挡住机器人批量加群。链接失效或被重置时，以本页和首页上的为准——这里永远是最新的。

三个平台会发一样的内容吗？

不会。群组是即时交流，X 是碎片想法，哔哩哔哩是整理过的长内容。同一个话题可能三处都出现，但形态不同：群里先聊，X 上补一句，最后整理成视频。

会回复私信吗？

会看。技术问题建议直接发群里，回复更快，也能留下记录给别人参考。涉及具体文件、链接的求助，群里更方便贴出来。

这个站用什么做的？

手写 HTML / CSS / JS，没有框架也没有构建步骤，托管在 GitHub Pages。发布源的配置过程写在 部署页，包括分支发布和 Actions 发布两种方式。

能转载 / 引用这里的内容吗？

个人使用随意，注明来源即可。批量搬运、去掉出处二次发布，先来群里说一声。
