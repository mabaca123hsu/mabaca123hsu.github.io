关于 TSAI

我是 TSAI。这个站点不是博客，而是一个入口页—— 把我分散在三个平台的内容收拢到一处，别人只需要记一个地址。

内容大致围绕三类：折腾记录（工具、系统、各种踩坑与复现）、 资源分享（值得留下的东西）、以及视频（把过程讲清楚）。 想即时交流就进 Telegram 群组，想看完整叙述就去哔哩哔哩。

站点本身是纯静态的 HTML / CSS / JS，没有框架、没有统计脚本、没有 Cookie， 托管在 GitHub Pages 上。部署方式写在这里。
